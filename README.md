# ArabOSINT - أداة الاستخبارات مفتوحة المصدر الموحدة

**برمجة وتطوير:** علي ماهر محي  
**اسم المشروع:** ArabOSINT (Arab OSINT Fusion)

---

## 📌 نبذة عن الأداة
أداة **ArabOSINT** هي منصة تجميع معلومات واستخبارات المصدر المفتوح (OSINT) موحدة، تعمل عبر واجهة ويب رسومية (GUI) محلية على جهازك (`Localhost`).  
تم تطويرها لتسهيل عمل الباحثين الأمنيين والمستكشفين عبر دمج عدة أدوات OSINT قوية في واجهة واحدة دون الحاجة للتعامل المباشر مع أوامر التيرمينال المعقدة.

---

## 🛠️ الأدوات المدمجة في المنصة
1. **Sherlock**: للبحث عن اسم المستخدم (Username) عبر مئات المنصات ومواقع التواصل الاجتماعي.
2. **Holehe**: للتحقق من البريد الإلكتروني (Email) والتنقيب عن الحسابات والمواقع المرتبطة به.
3. **Phonenumbers**: لتحليل أرقام الهواتف دولياً وجلب بيانات الدولة ومزود الخدمة والتحقق من صحة الرقم.

---

## 📥 طريقة التنزيل والتثبيت (Kali Linux / Ubuntu / Debian)

افتح التيرمينال (Terminal) واكتب الأوامر التالية بالترتيب:

```bash
# 1. استنسخ المستودع من GitHub
git clone [https://github.com/osint-fusion/ArabOSINT.git](https://github.com/osint-fusion/ArabOSINT.git)

# 2. الدخول إلى مجلد المشروع
cd ArabOSINT

# 3. إعطاء صلاحيات التشغيل لسكربت التثبيت
chmod +x setup.sh

# 4. تشغيل التثبيت التلقائي
./setup.sh

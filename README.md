# ArabOSINT - أداة الاستخبارات مفتوحة المصدر الموحدة

**برمجة وتطوير:** علي ماهر محي  
**الإصدار:** 2.0  
**الترخيص:** مفتوح المصدر (أغراض أمنية وتعليمية)

---

## 📌 نبذة عن الأداة
**ArabOSINT** هي منصة استخبارات مفتوحة المصدر (OSINT) تعمل بواجهة ويب رسومية (GUI) احترافية وبسيطة. صُممت لتسهيل عمل الباحثين الأمنيين والمستكشفين عبر دمج أشهر أدوات جمع المعلومات في واجهة واحدة دون الحاجة لحفظ أوامر التيرمينال المعقدة.

---

## 🛠️ الأدوات المدمجة في المنصة
1. **Sherlock**: للتعقب والبحث عن أشكال تواجد أسماء المستخدمين (Usernames) عبر أكثر من 300 موقع ومنصة اجتماعية.
2. **Holehe**: للتنقيب عن الحسابات والمواقع المربوطة بعنوان بريد إلكتروني مُحدد (Email).
3. **Phonenumbers**: لتحليل واستخراج بيانات أرقام الهواتف دولياً مع تحديد الدولة ومزود الخدمة والمنطقة الزمنية.

---

## 📥 طريقة التثبيت على (Kali Linux / Ubuntu / Debian)

افتح التيرمينال (Terminal) واكتب الأوامر التالية بالترتيب:

```bash
# 1. استنسخ المستودع من GitHub
git clone [https://github.com/osint-fusion/ArabOSINT.git](https://github.com/osint-fusion/ArabOSINT.git)

# 2. ادخل إلى مجلد المشروع
cd ArabOSINT

# 3. إعطاء صلاحيات التشغيل لسكربت التثبيت وتشغيله
chmod +x setup.sh
./setup.sh
